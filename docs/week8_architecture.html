02 Company Tab — Six parallel /research calls
The Company tab was originally a single Claude call asking for five dimensions in one prompt. Output quality on the last two dimensions was visibly weaker — recency bias against trailing context. Decomposed into six parallel calls, each scoped to one aspect, total wall-clock dropped from ~50s to ~15s and per-aspect quality became uniform.

04 The AI / Non-AI Seam — Where Claude Stops
Alex's rule from Week 4: AI reads from but never writes directly to deterministic systems; tool-use is the seam. In CTO Compass, every component on the swimlane canvas is positioned by code, not by Claude. If we had asked Claude for coordinates, the layout would drift every call. Claude returns nouns; code computes pixels.

06 Configured ≠ Enforcing — The Latent Defect
The single most generalisable architectural lesson of the capstone. Branch protection on main had been configured in Week 1 of this product, visibly present in the GitHub UI through every subsequent week, and visibly being bypassed on every direct push. Three independent defects compounded to make the gate ornamental rather than enforced. The discovery: every architectural contract needs an enforcer behind it, and the only proof is running the failing case.
DEFECT 1
CI trigger
ci.yml had on: pull_request only — no push trigger. Direct pushes to main never created a check run for protection to evaluate.
DEFECT 2
enforce_admins
Set to false at repo creation. Admin (the only user) bypassed the rule on every push with a warning that was easy to ignore.
DEFECT 3
default_branch
GitHub had setup/scaffold-and-schema as default, not main. gh pr create silently retargeted PRs against the wrong base.
Before the fix — the bypass warning we missed for weeks
remote: Bypassed rule violations for refs/heads/main: remote: - Required status check "test" is expected.
After the fix — the rejection that proves the gate now bites
remote: error: GH006: Protected branch update failed for refs/heads/main. remote: - Required status check "test" is expected. ! [remote rejected] main -> main (protected branch hook declined)
Every contract needs an enforcer. Configured ≠ enforcing. Run the failing case.
